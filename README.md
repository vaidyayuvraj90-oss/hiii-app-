# 📊 Pocket PPT Viewer (Android APK + Web App)

A lightweight, 100% offline-capable PowerPoint (`.pptx`) presentation viewer built with HTML5, CSS3, JavaScript (`JSZip`), and wrapped into a native Android `.apk` using **CapacitorJS** and **GitHub Actions** — no Android Studio installation required!

## 🚀 How to Build the Android `.apk` Automatically on GitHub
1. Create a new repository on [GitHub](https://github.com/new).
2. Upload all extracted files from this ZIP (make sure to include the `.github/workflows/build-apk.yml` folder).
3. Go to the **Actions** tab in your GitHub repository.
4. Click on the **Build Android APK** workflow run.
5. Once it finishes (takes ~2-3 minutes), scroll down to **Artifacts** and download **`Pocket-PPT-Viewer-APK`**!
